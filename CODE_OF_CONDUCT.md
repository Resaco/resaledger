# Code of Conduct

ResaLedger adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. The official text at that address is the one that applies; it is linked rather than copied, so that it cannot drift.

## Scope

It applies in every space of this project: the repository, its issues, pull requests and discussions, reviews and commit messages, and any space where someone represents the project. It applies to people and to the agents that act for them; the person who runs an agent answers for what it posts.

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub's private reporting form: open the repository's **Security** tab, choose **Report a vulnerability**, and start the title with "Conduct:". Only the maintainers see the report. Every report is reviewed and investigated promptly and fairly, and the reporter's privacy is respected.

The maintainers enforce the code of conduct with the community impact guidelines of the Contributor Covenant 2.1: correction, warning, temporary ban and permanent ban.

Security problems are not conduct reports: see [SECURITY.md](SECURITY.md).
