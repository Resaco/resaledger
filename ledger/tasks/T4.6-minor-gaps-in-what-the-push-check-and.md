## Notes

Finding 8: on a push to the base, GitHub's committer address exempts a commit only when it is a merge commit or its subject ends in GitHub's squash form, ` (#N)`. The output counts these commits ("1 exempt as GitHub's merge or squash commit by the committer address"). Spec 10 and 12, the format reference, the CI guide and the team guide say that the push check trusts the address and that the base must be protected. A rebase merge's copies and a web-editor commit are now checked like any commit.

Finding 9: `treeReader` gains `mode(path)`. A hook whose mode was `100755` and becomes anything else, including a symlink, is a weakening `hooks/<name>` change; the mode is folded into the same change as the text, so each id appears once. A change to `.gitattributes` is listed under the new id `gitattributes`.

Finding 10: record text in the comment and summary is escaped (backslash, `*`, `_`, `[`, `]`, `~`, unmatched backticks, and `<` as before), while balanced code spans stay as written, so evidence such as `` `npm test`: 3 of 3 `` still renders as code. The golden fixture now carries a title with emphasis.

Each test was checked against the reverted fix: it failed there and passes now.
