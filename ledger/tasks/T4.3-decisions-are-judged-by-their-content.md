## Notes

A decision counts only when it sits directly in `decisions/` and the merge base has no file with the same text, so a renamed or copied decision lets nothing through. `ci` refuses a pull request that deletes or renames a decision or log entry the merge base has. Finding 14 is answered in the team guide and spec 10: a loosened rule applies once it is on the base, so the work that uses it follows in a later pull request.
