## Notes

`ci` now checks each task in the head that names another lane (any status) and differs from both the merge base and the base against that lane's branch: `refs/remotes/<remote>/<lane>`, else `refs/heads/<lane>`, without a fetch. The copies must be byte-identical. A difference fails when either copy holds the task; a held task whose lane has no branch in the clone fails too. A done task that no lane's branch still holds stays editable by anyone, as spec 6.2 says. Both reproductions of finding 4 now fail, and the stacked control passes.

The cost is three git processes in total, whatever the number of tasks: `git remote`, one `for-each-ref` with every candidate ref, and one `cat-file --batch`. The test with 50 foreign held tasks on 50 lanes passes within `budget(3000)`.
