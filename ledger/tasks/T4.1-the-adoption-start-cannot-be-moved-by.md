- Status: done

  - [adoption.test.mjs](../../test/adoption.test.mjs) and [ci.test.mjs](../../test/ci.test.mjs), "a branch that deletes the configuration and adds it again cannot hide a commit between": the unrecorded commit is refused on a pull request and on a push; both tests fail on the previous `adoptionStart`.

## Notes

`adoptionStart` keeps a start whose tree has `.resaledger.json`, and otherwise moves it to the oldest commit after it that added the file; `adoptionCommit` is the oldest such commit too, so `handoff`, pre-push and `ci` all judge every commit made since the first adoption. A known limit stays: without a remote, `handoff` starts its range at the last commit that added a stamp, and a stamp is a claim anyone can write (spec 12).
