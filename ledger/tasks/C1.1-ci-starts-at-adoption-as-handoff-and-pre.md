# C1.1 ci starts at adoption, as handoff and pre-push do

- Status: todo
- Depends on: C3

## Plan

Goal: `ci` judges only the commits made since the project adopted ResaLedger, as `handoff` and pre-push do since T3.3 and T3.2. Seen while preparing the first push after M4: a push to the base, or a pull request, that also carries commits made before the move from 0.x would have every such commit refused, because its tree has no task file.

- On a push and on a pull request, move a range start older than the commit that added `.resaledger.json` up to that commit (`adoptionStart`).
- Acceptance: a pull request and a push whose range includes a 0.x commit that names a task from `work/ledger.md`, followed by the migration commit, pass; a code commit after the migration that names no task still fails.
- After C3, which changes `ci.mjs` now.
