# 2026-10-15 · `claim`, the agent hooks, and `migrate` made safe at the edges of git

W4, A1 and T5.1 merged. `claim` takes a task only when no visible lane holds it, in this worktree, the other worktrees or the pushed branches, records a takeover with `--take`, creates the lane branch or worktree when asked and pushes the claim in the team preset. `hook claude|codex <event>` stops an agent before `--no-verify`, a change to `core.hooksPath`, a forced push, a push to a protected branch, the project's deny rules and edits on a protected branch, through a shell parser that ignores quoted text; at the end of a turn it reminds once when the work is not handed off. `migrate` now refuses paths that git ignores, symlinks and untracked targets, bytes that are not UTF-8, names that differ only in case and names Windows reserves, and prints the undo when writing fails halfway. On review the lead found that the recorded Claude Code input carried a documentation path into an agent's private folder, which the hygiene scan refuses, and fixed it in the commit itself before anything was pushed. The second CI run passed on Linux and macOS; on Windows, npm could not be started without a shell and one time budget was too tight, both fixed. 679 tests pass on Node 24, 22 and 20.
