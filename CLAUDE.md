## Build workspace

The build in this repository is run from [`ledger/`](ledger/README.md). Before any work, read [`ledger/AGENTS.md`](ledger/AGENTS.md) and [`ledger/STATUS.md`](ledger/STATUS.md), then run `node ledger/scripts/records.mjs work`. Before you stop, run `node ledger/scripts/records.mjs handoff`.
