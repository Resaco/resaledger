# ResaLedger 1.0.0

ResaLedger is a task ledger inside your repository that coding agents can't skip, can't fake and can't collide on. Every task, decision and log entry is a small Markdown file in the repository; git hooks, agent hooks and a CI check refuse work that is not recorded; and a stamp ties a passing run of your own checks to the exact code it ran on.

1.0 is the first release under this name. It replaces agent-ledger 0.x, whose few shared files conflicted as soon as several people or agents worked in parallel.

## Highlights

- **Parallel lanes.** A lane is a branch. `claim <id> --worktree <path>` gives a task its own branch and folder, only the lane that holds a task changes it, and three agents in three worktrees never edit the same file.
- **Enforced where an agent cannot talk its way past.** The git hooks refuse a code commit with no `Task:` line, invalid records and a change to another lane's task. Agent hooks for Claude Code, Codex, Cursor, Gemini CLI and GitHub Copilot stop `--no-verify`, forced pushes, edits on a protected branch and commands that throw away another lane's work. CI judges each pull request by the rules of the branch it merges into.
- **Checks that ran, on the code that merges.** `verify` runs your project's own checks on the committed code and writes a stamp named after it; `handoff` and CI ask for it, and CI reruns the gates.
- **Changes to the rules are visible.** A pull request that weakens enforcement, such as a removed gate or an unprotected branch, fails unless it adds a decision that names the change.
- **Setup from what is true.** `init` runs the project's own checks once and keeps those that pass as gates, and writes a solo or a team preset.
- **No dependencies.** The guard is one file in your repository, for Node 20 or newer.

## Install

```bash
npx resaledger init
```

[The README](https://github.com/Resaco/resaledger#readme) has the quickstart and a demo; [the guides](https://github.com/Resaco/resaledger/tree/main/docs) cover working alone, in a team, in CI and with each agent.

## From agent-ledger 0.x

```bash
npx resaledger migrate --dry-run
```

`migrate` converts a workspace in place, refuses before writing anything if a single line of the old records would be lost, and prints the commit command and the undo command. Merge or close open lanes first, or rebase them onto the migrated base afterwards. [Moving from 0.x](https://github.com/Resaco/resaledger/blob/main/docs/guides/migration.md) has the details.

## Built with itself

This repository was built with ResaLedger: its own tasks, decisions and log are in [`ledger/`](https://github.com/Resaco/resaledger/tree/main/ledger), it moved from 0.x with its own `migrate`, and a second model reviewed the guard, `migrate` and the CI check before the release, each review recorded with its findings and fixes.

The full list of changes is in [CHANGELOG.md](https://github.com/Resaco/resaledger/blob/main/CHANGELOG.md).
