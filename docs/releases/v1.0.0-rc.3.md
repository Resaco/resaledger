# ResaLedger 1.0.0-rc.3

The third release candidate for ResaLedger 1.0.0, with support for repositories that use Git LFS. It is published to npm under the `next` tag:

```bash
npx resaledger@next init
```

What changed since rc.2:

- In a repository that uses Git LFS, ResaLedger's pre-push hook runs Git LFS's pre-push after its own checks, so pushes upload the LFS objects as Git LFS's own hook would. A refused push uploads nothing.
- `init` and `migrate` recognise the hooks Git LFS wrote into `.githooks/`, replace only its `pre-push`, and say how to bring it back.
- `init` refuses a hook manager's `pre-push` that already runs `git lfs pre-push`, and both commands refuse while an ignore rule hides a hook they must commit.

Known limit: the Git LFS path is not tested on Windows yet.

Please report what breaks in an issue; report a way past the hooks or CI privately, as [SECURITY.md](../../SECURITY.md) says. The changes are listed in [CHANGELOG.md](../../CHANGELOG.md#100-rc3---2026-10-16).
