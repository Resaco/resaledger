# ResaLedger 1.0.0-rc.1

The release candidate for ResaLedger 1.0.0. It is published to npm under the `next` tag, so install it by name:

```bash
npx resaledger@next init
```

Everything 1.0.0 will hold is here; [the 1.0.0 notes](v1.0.0.md) describe it. Please report what breaks, especially on Windows and with agents other than Claude Code, in an issue; report a way past the hooks or CI privately, as [SECURITY.md](../../SECURITY.md) says.

The changes are listed in [CHANGELOG.md](../../CHANGELOG.md#100-rc1---2026-10-15).
