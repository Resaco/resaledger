# ResaLedger 1.0.0-rc.2

The second release candidate for ResaLedger 1.0.0, with the fixes from the first installations of rc.1 in real repositories and the first migrations of agent-ledger 0.x workspaces. It is published to npm under the `next` tag:

```bash
npx resaledger@next init
```

What changed since rc.1:

- `agent.pushNeedsHandoff` lets a project refuse an agent's push while `handoff` fails.
- `migrate` keeps edited 0.x template sections active, renames the old configuration file in `.gitattributes`, and says when agent hooks are missing.
- `init` tries the `check` script and lists `test:` and `lint:` scripts without running them; `new` writes an empty Evidence line.
- Short field names and configuration keys no longer catch unrelated names as typos.
- The CI comment no longer mentions people or references issues from the records.
- A guide to work outside the code, such as content in a CMS or a server setting.
- If `npx` stops with `EOVERRIDE` in your project, run `npx --prefix "$(mktemp -d)" resaledger init`.

Please report what breaks in an issue; report a way past the hooks or CI privately, as [SECURITY.md](../../SECURITY.md) says. The changes are listed in [CHANGELOG.md](../../CHANGELOG.md#100-rc2---2026-10-15).
